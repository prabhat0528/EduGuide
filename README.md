# EduGuide – Personalized Learning & Mentorship Platform

EduGuide is a full-stack AI-powered platform built to deliver personalized learning roadmaps, expert mentorship, and intelligent guidance tailored to individual goals.

It bridges the gap between scattered learning resources and real-world career guidance by combining structured planning with AI-driven insights.

---

## Key Features

### Authentication & Role-Based Access Control
- Secure login and signup system
- Role-based access for learners and mentors
- Ensures personalized and protected user experience

### AI-Powered Learning Roadmaps
- Generate customized monthly and weekly plans
- Structured learning paths for any domain or skill
- Helps users stay consistent and goal-oriented

### Mentor Interaction System
- Connect with experienced industry professionals
- Gain real-world insights and career guidance
- Enables meaningful learner–mentor engagement

### RAG-Based Intelligent Chatbot
- Powered by LangChain and AI models
- Provides context-aware and accurate responses
- Helps users navigate the platform and resolve queries instantly

---

## What Makes EduGuide Unique?
- Combines AI, mentorship, and structured learning in one platform
- Focuses on practical, real-world guidance
- Built with a scalable backend architecture

---

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- AI Layer: Flask, LangChain, Scikit-learn
