🚀 EduGuide – Personalized Learning & Mentorship Platform

EduGuide is a full-stack AI-powered platform designed to provide personalized learning roadmaps, mentorship, and intelligent guidance to users based on their goals and interests.

It bridges the gap between learning resources and real-world guidance by combining structured planning with AI-driven insights.

📌 Features
🔐 Authentication & Role-Based Access Control
  Secure login/signup system
  Different roles for users and mentors
🧠 AI-Powered Learning Roadmaps
  Generate personalized monthly & weekly plans
  Structured path for any domain or skill
💬 Mentor Interaction System
  Connect with experienced professionals
  Get real-world insights and career guidance
🤖 RAG-Based Chatbot
  Context-aware responses using LangChain
  Helps users navigate platform & queries instantly
